# Արցախ — историческое приложение для всех армян 🇦🇲

Трёхъязычное (**հայերեն · русский · english**) веб-приложение об Арцахе:
история, святыни, культура, память — с **настоящими фотографиями** и играми внутри.

> 🌍 **Сайт онлайн (открывается у любого по ссылке):**
> **https://hrahatyesayan-stack.github.io/artsakh/**
> Репозиторий: github.com/hrahatyesayan-stack/artsakh · обновление сайта — `git push` (GitHub Pages, ветка `main`).

## Как открыть
Дважды кликни по **`index.html`** (нужен интернет — фотографии загружаются
из Wikimedia Commons). Переключай язык кнопками **ՀԱՅ / РУС / ENG** вверху справа.

## Что внутри (`index.html`)
- **Главная** — большое фото монастыря Гандзасар, название «Արցախ», три языка.
- **История** — лента из 7 эпох с фотографиями и фактами (от 763 г. до н.э. до наших дней).
- **Святыни** (10) — Гандзасар, Дадиванк, Амарас, Казанчецоц (Шуши), Степанакерт, Тигранакерт, Егише Аракял, Ериц Манканц, Андаберд, Ванкасар.
- **Карта** — интерактивная карта Арцаха (Leaflet), 9 меток святынь и городов.
- **Культура** (8) — хачкар, дудук, гранат, алфавит, женгялов хац, ковёр, гата, карабахская лошадь.
- **Личности** (5) — Тигран Великий, Месроп Маштоц, Гасан-Джалал, Монте Мелконян, Никол Думан.
- **Природа** — каньон Каркар (Унот), Сарсанг, платан Тнджри, пещера Азох.
- **Знаете ли вы?** — сменяющиеся факты об Арцахе (на трёх языках).
- **Звук** — кнопка 🔈 включает мягкий «дудук»-эмбиент (выкл. по умолчанию).
- **Фотогалереи** — клик по снимку открывает фото во весь экран; у многих святынь несколько фото со стрелками (‹ ›). Есть кнопка «↑ наверх».
- **Поиск** — кнопка 🔍 ищет по святыням, культуре, личностям и эпохам (на трёх языках).
- **Игры** — викторина, аркада «Всадник Арцаха», заставка «Сквозь века».
- **Память** — звёздный раздел-посвящение: «Մենք ենք մեր սարերը».

## Игры (отдельные страницы, со ссылкой «← Արցախ» назад)
- `quiz.html` — викторина по 7 эпохам (вопросы, факты, 3 жизни, рекорд).
- `runner.html` — аркада-бегалка про всадника.
- `story.html` — атмосферное путешествие по эпохам.

## Фотографии
Источник — **Wikimedia Commons** (свободные лицензии); авторы указаны в подвале и при просмотре фото.
Главные снимки **скачаны локально** в папку `img/` (ради постоянства — не зависят от ссылок Wikimedia); дополнительные фото в галереях пока подгружаются с Wikimedia. Атрибуция сохраняется через карту `SRC` (локальный путь → исходный URL).

## Языки и тексты
Все тексты — в объекте `T` (hy / ru / en) и в массивах `TIMELINE`, `LANDMARKS`,
`CULTURE`. Чтобы добавить язык или поправить текст — редактируй там.
